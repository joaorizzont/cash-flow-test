# Architecture Decision Records

Cada decisão arquitetural significativa é registrada como um ADR: o contexto que exigiu uma escolha, a decisão, as alternativas descartadas e as consequências que ela traz. A prática está descrita na [ADR-0001](0001-record-architecture-decisions.md).
